## 5. Cross-Cutting Risk Resolution

| Risk | Resolution |
|---|---|
| **64 KB pool exhaustion** on step-3 with many rows → `StoreProhibited` (prior bench-crash mode) | Hard-cap rows at `CB_MAX_DYN_ROWS=12`/channel (D5); single rows-container + `lv_obj_clean` re-render (D9); ~12 rows × ~5 objs + chrome ≈ 30-40 KB, fits the 64 KB pool but tight → cap is **mandatory** (R3). NO `lv_draw_*` on the canvas (D8). |
| **Keypad-field capacity** — 8-slot array silently disables value boxes past slot 8 (guard :515) | Bump to `[32]` + cap rows so worst case = `3 + 12×2 = 27 ≤ 32`; reset `s_kp_field_n=0` per step-3 render; static-array binding stays leak/dangle-free (D5). |
| **Canvas PSRAM leak** — `lv_obj_del` does not free the external buffer (:2455) | Alloc-on-enter / free-on-leave step-4 + on tab teardown; track outgoing step; guard double-free; dedicated `cb_canvas_buf` (D6). |
| **Bounded draw cost** — per-frame UI must be allocation-free | `wave_*` direct-pixel writes only, O(W×lanes), no per-frame malloc; re-render only on commit events, not per digit (D8/D9). |
| **Preview-vs-compiler fidelity** — hand-coded expansion can't call `dslCompile`; CCW cam reversal omitted | Mirror `cbExpandWheel` + LCM math exactly incl. crank-only doubling + 4096 cap; preview is phase-only (documented, D13); APPLY uses the real Compiler via `MSG_LOAD_DSL` and `g_dsl_error` surfaces any divergence (D12). |
| **Dangling keyboard pointer** on teardown (removed `close_dsl_panel`'s `kb_hide`) | New builder calls `kb_hide()` on step transitions + tab teardown before deleting any textarea/value-box (D17). |
| **`buttonmatrix` map dangling** | None added by the builder (D7 uses real buttons); the kept `kKeypadMap` stays `static const char* const` at file scope (ui_lvgl.cpp:180). |
| **Tab-index shift** (CUSTOM at idx1 pushes ADVANCED to idx2) | No code references tab indices by number (pointers only; `on_tabview_changed` no-op) — verified safe (D1). |
| **Emitted DSL length** | `char[512]`; worst 3×12-row config is well under 512 (R4) and under the Validator cap. |
