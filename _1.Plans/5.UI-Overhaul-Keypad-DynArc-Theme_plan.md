## 1. Context

Cycle-4 UI is a 2-tab `lv_tabview` (HOME / ADVANCED) with five lazily-created full-screen overlay pages (Custom/Sweep/Comp/DSL/Wave). Run-control is already a single clean callback: `s_on_run(true/false)` → `main.cpp` `on_ui_run` → `MSG_START`/`MSG_STOP` → `gGen.start()`/`gGen.stop()` (verified main.cpp:257,461-483). `ui_force_output_off()` (ui_lvgl.cpp:1012-1017) is the idempotent stop primitive. Live page arcs read `sweepCurrentRpm()` at 10 Hz (`update_live_arc` :1075-1084).

Cycle-5 adds four behavioral changes + one visual change, **entirely inside `ui_lvgl.cpp`** (plus three font flags in `lv_conf.h`):

1. **Pages can START output** (U1/U2): add symmetric `ui_force_output_on()`; rename page **APPLY → START** on Sweep/Comp/Custom — each sends its config AND starts output AND stays open.
2. **Remove the HOME compression trigger** (U3a); make the **Compression page arc dual-mode** (U3b): user-draggable RPM when stopped, read-only output visual when running.
3. **ON/OFF status pill** below the arc on every START/STOP page (U4).
4. **Modal numeric keypad** replaces spinbox steppers (BRIEF [4]); exact button sizing (BRIEF [5]); dynamic arcs (BRIEF [6]); DSL arc-removal + scrollable help (BRIEF [7]).
5. **New unified HUD theme** (cyan accent, distinct surface, FILLED buttons, glow on primary actions) applied everywhere incl. keypad + on-screen keyboard.

**FREEZE assertion (verified):** every behavior resolves to an existing UI-callable surface. START reuses `s_on_run(true)`→`MSG_START`; configs reuse `MSG_SET_SWEEP`/`MSG_SET_COMPRESSION`/`s_on_custom`; the dual-mode arc reuses `on_arc_changed`(:1099-1118)+`s_on_rpm`; dynamic arcs reuse `sweepCurrentRpm()`. **No new `MSG_*`, no `ui_init`/`ui_update_*`/`ui_lvgl.h` change, no `main.cpp` edit.**
