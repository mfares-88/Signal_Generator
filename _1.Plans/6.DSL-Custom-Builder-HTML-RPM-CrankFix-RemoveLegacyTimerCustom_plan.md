## 1. Context & Goals

This project is an ESP32-S3 (Guiton JC4827W543) engine CKP/CMP signal generator. Build flag `SIGGEN_BACKEND_TABLE=1` is ALWAYS defined (`platformio.ini:32`); the WROOM env is commented out, so the legacy `TimerCkpGenerator` backend and every `#if !defined(SIGGEN_BACKEND_TABLE)` branch are DEAD in the real build. The active byte-table backend is `TableCkpGenerator`; the active custom path is UI custom panel → `s_on_custom` → `on_ui_custom` → `MSG_SET_CUSTOM` → `dslCompileSignalConfig` → `gGen.apply`.

**Three locked user decisions drive this cycle:**

1. **New TOP-LEVEL "CUSTOM" tab = stepped guided pattern builder** (`HOME | CUSTOM | ADVANCED`). The guided builder fully subsumes BOTH the legacy "Custom Pattern" `SignalConfig` modal AND raw DSL text entry. Remove the legacy "Custom Pattern" feature end-to-end and the timer-based custom/legacy backend interlinks *associated with it alone* (do NOT remove shared infra: `SignalConfig`/`GapPosition`/`gCfg`/`IGenerator`).
2. **Add an "Output Waveform" button** that visualizes the basic multi-lane waveform produced by the builder's DSL inputs, so the user confirms the resulting shape before applying.
3. **RPM fix = universal crank RPM.** `period_us = 60000000 * degrees / (360 * rpm * slot_count)`. Consequence: 720-degree CMP runs at half its current rate (cam = ½ crank, physically correct); the 800→1600 RPM doubling bug on CKP+CMP tables is fixed. Store the degree span in the generator so `setRpm()` (sweep fast path) stays correct.

**Interim-vs-target SCOPE SPLIT (authoritative):**
