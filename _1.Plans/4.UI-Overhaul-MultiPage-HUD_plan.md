## 1. Context

The shipped UI (`lib/ui_lvgl/ui_lvgl.cpp`, ~1955 lines) is a **single `screen_main` with LEFT/RIGHT panes** plus **5 lazily-created full-screen modal overlays** (custom/sweep/comp/dsl/wave) via `open_*_panel()`/`close_*_panel()`+`lv_obj_del`. This cycle restructures it into a **2-tab `lv_tabview`** (HOME + ADVANCED), with the 5 panels reborn as **full-screen pages** reached from a vertical scrollable Advanced list, each with a top-left `< Back` that commands output OFF before returning. Plus 5 refinements, a unified dark-automotive HUD palette, and a per-page density table.

**R1 conclusion:** the cross-core sync engine (`s_ui_mux`/`apply_pending_updates`), the 64-pattern categorized dropdown + fuzzy scorer, the channel-LED apply logic, the on-screen keyboard lifecycle, and the direct-to-canvas waveform pixel helpers are all **parent-agnostic = PRESERVE-AS-IS** (addressed by file-static pointer). Only `create_main_screen()`'s pane layout is **REPLACED** (by the tabview); the 5 `open_/close_` modals **RESTRUCTURE** into pages. CUSTOM (no trigger today) gains one as the 5th Advanced row.

**R5 assertion — FREEZE `src/main.cpp`, `lib/sweep_compression`, `lib/dsl`:** every behavior resolves to an existing UI-callable surface. Back-stops-output + Sweep/Comp STOP reuse `s_on_run(false)` → `on_ui_run(false)` → `MSG_STOP` (`main.cpp:255-262`). The Home compression toggle reuses the existing `MSG_SET_COMPRESSION` sender + the `g_comp_*` externs (`NvsStore.h`, already `#include`d by `ui_lvgl.cpp:149`). Live page arcs reuse `sweepCurrentRpm()` (`SweepCompression.cpp:470`). Waveform freeze caches `ui_get_edge_counter()` (lock-free). **No new `MSG_*` type, no `ui_init`/`ui_update_*` signature change.**

**Single `lv_conf.h` change (Agent C):** ADVANCED's header font is montserrat_16, currently disabled (`LV_FONT_MONTSERRAT_16=0`, `lv_conf.h:488`). All other widgets (TABVIEW/LIST/MENU/KEYBOARD/CANVAS/ARC) already enabled.

In `on_wave_drag`: get the indev via **`lv_indev_active()`** (note: `lv_event_get_indev(e)` *also* exists in 9.2.2 and is equally valid — earlier "does not exist" claim was wrong; pick either); `lv_indev_get_vect(d,&v); if(!v.x) return;` `visible=...; if(visible>=(slot_count<<8)) return;` (no-op at full-fit) `delta = -(int64_t)v.x*visible/w; panL += delta;` clamp `[0,(slot_count<<8)-visible]`; `dirty=true`.
**Slow-pan defect fix (reviewer MAJOR):** `my_touchpad_read` (`:285-318`) coalesces moves <3 px within 50 ms by returning the stale point → slow fine-drags report zero vector and never pan. Add a file-static `s_wave_drag_coalesce_off` flag; `open_wave_panel` sets it `true`, `close_wave_panel` sets it `false`; in `my_touchpad_read`, **skip the <3 px/50 ms suppression when the flag is set** so slow drags register on the WAVE page only (the arc-coalescing rationale doesn't apply there). This is the agreed remedy for smooth pan.

**E-wave-7 — PAUSE/PLAY.** `on_wave_pause`: `s_wave_paused=!s_wave_paused; if(paused) s_wave_frozen_cursor=ui_get_edge_counter();` relabel PAUSE↔PLAY; `dirty=true`. Lanes always static-from-table; only the cursor freezes (Ref5c). Backend keeps running.

**E-wave-8 — Single render entry.** PRESSING/zoom/pause cbs only set `s_wave_dirty`; the existing 50 ms (20 Hz) wave timer is the sole render path. Cost bounded as today: w cols × 3 lanes × `vfill/hfill` ≤ ch px, all clamped — zero allocation.
