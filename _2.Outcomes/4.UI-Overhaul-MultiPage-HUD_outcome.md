## 2. Direct Answer — Load of the Live Dynamic RPM Arc (your pre-implementation question)

Confirmed against the shipped code: each page arc is **created lazily on page-open and `lv_obj_del`'d on Back**, refreshed by a **100 ms (10 Hz)** `lv_timer` calling `lv_arc_set_value(arc, sweepCurrentRpm())` — i.e. **~1 KB transient LVGL-pool per open page, 0 KB resident, one small partial redraw at 10 Hz, ZERO ISR/hardware impact** (the arc only displays an RPM the Core-1 sweep task already computes; the generator ISR is untouched). The arc is **dimmed/zeroed when output is stopped** so it never shows a misleading RPM. This matched the estimate given before implementation.

## 5. Deviations & Follow-ups (faithful report)

1. **Waveform width ~464px, not 480px edge-to-edge.** The WAVE canvas spans the page *content* width (480 − 2×8px unified page gutters). This honors "fills the width" within the themed page but is not literal screen-edge-to-edge. **One-line change** (drop the canvas-container horizontal padding / anchor at screen x=0) if you want true 480px — your call (bench checklist item).
2. **`lv_obj_set_style_pad_gap` doesn't exist in 9.2.2** → used `pad_row`/`pad_column` (the plan's listed alternative). No behavioral impact.
3. **DSL help examples trimmed to exactly one crank-only + one crank+cam** (per Decision 8). Two extra forms that *do* parse (`1,C,S,1/2,2`, `2,c,A,10,710`) were dropped to honor the one-each mandate + ASCII budget; the A-tail is still documented. "half-moon cam" relabeled "1-tooth cam" (accurate to the syntax).
4. **Benign compile warning** at `ui_lvgl.cpp:994` — `-Wdeprecated-enum-enum-conversion` on `LV_PART_MAIN | LV_STATE_CHECKED` (standard LVGL 9.2.2 part|state idiom). Compiles clean; no `-Werror`. Left as-is to avoid out-of-design churn.
5. **Leftover unused symbols** (`LEFT_X..RIGHT_H`, `SCREEN_H`, `lbl_title`, `lbl_sweep_live`) remain; harmless under current flags. Optional future cleanup.
6. **Comp-page APPLY** stays on the page and doesn't itself resync the Home toggle, but returns via Back/tab which do — net behavior correct.
